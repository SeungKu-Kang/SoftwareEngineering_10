## Commit Message Convention

커밋 메시지는 아래 형식을 사용합니다.

```text
type: summary
```

`type` 목록:
- `feat`: 새로운 기능 추가
- `fix`: 버그 수정
- `docs`: 문서 수정
- `style`: 코드 포맷팅, 세미콜론 누락 등 비기능적 변경
- `refactor`: 기능 변화 없는 코드 구조 개선
- `test`: 테스트 추가 또는 수정
- `chore`: 빌드, 설정, 패키지 관리 등 기타 작업

작성 규칙:
- summary는 한 줄로 간단하고 명확하게 작성
- 첫 글자는 동사 원형으로 시작
- 필요하면 한 커밋에는 한 가지 목적만 담기

예시:

```text
feat: add login page
fix: resolve signup form validation error
docs: update requirement list
refactor: simplify reservation service logic
chore: add gitignore for node modules
```
